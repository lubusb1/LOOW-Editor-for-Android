# 网页版预设编辑器

在浏览器里编辑壁纸预设，导出的就是手机端渲染器直接读取的那套 JSON。
手机 App 里跑的是同一份文件（构建期同步进 assets），所以两端行为一致。

## 打开方式

直接双击 `index.html`（不需要服务器、不需要联网、不需要安装任何东西）。

- 推荐浏览器：Chrome / Edge
- 如果浏览器拦了本地文件，可以在本目录执行 `python -m http.server 8080`，然后访问 <http://127.0.0.1:8080>

## 能做什么

| 区域 | 能力 |
|---|---|
| 左栏 | 图层树（矩形 / 文本 / 图片 / 容器）、动画列表；增删、拖动排序、双击改名 |
| 中间 | 真实比例预览；点选、拖动移动、四角拖动改尺寸 |
| 右栏 | 位置 / 尺寸 / 圆角 / 旋转 / 缩放 / 透明度 / 颜色 / 渐变 / 羽化 / 视差 |
| 底部时间轴 | 播放头、关键帧拖动、插入 / 删除帧、六种缓动与曲线预览、触发方式、循环、时长 |
| 触发器 | 节点工作台：手势、命中图层、定时、出现时、变量变化，拖线成逻辑 |
| 导入导出 | 读入预设包 / 单个 JSON；导出单文件包或 3 个标准 JSON |

## 格式约定（与手机端完全一致）

- 坐标：`x / y / width / height` 都是**画布宽度的百分比**，原点左上角，y 向下
- 颜色：`#AARRGGBB`
- 关键帧：`t` 归一化 0..1、严格递增；**末帧可以早于 1**，之后保持末值
- 触发：`always`（常驻，壁纸可见即播）/ `tap`（点击）

导出的三个文件与手机端读取的完全对应：

```
manifest.json      # formatVersion / engineMinVersion / name / author / license
scene.json         # 场景树：root 容器 + 各类型图层
interactions.json  # 动画、规则、绑定
```

单文件包则是 `{ manifest, scene, interactions, resources }` 四合一，便于分享。

完整 schema 见仓库根目录的 `schema/`。

## 调试

`selftest.js` 是纯逻辑自测（`node selftest.js`）；`cdp.mjs` 可以连上 Chrome 的调试端口，
在页面里跑表达式、模拟点击。
